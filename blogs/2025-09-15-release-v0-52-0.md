Release v0.52.0 The release of Perses v0.52.0 introduces significant new features and improvements. This update expands Perses' observability capabilities by introducing support for logging and continuous profiling, along with new plugins for Pyroscope, Flame Chart, Loki, and log visualization. Additional enhancements include a heatmap panel for Prometheus histograms, a quick query viewer, panel group variable repeat, usability improvements, and upgraded CLI commands to streamline plugin development and schema testing.
