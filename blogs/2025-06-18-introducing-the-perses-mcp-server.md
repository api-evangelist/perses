<h1>Introducing the Perses MCP Server</h1> <p>We're thrilled to introduce the <strong>Perses MCP Server</strong>, now available in public beta. This new tool empowers you to interact with your Perses instances using natural language, opening up a world of possibilities for monitoring and visualization.</p> <p>With the Perses MCP Server, users can use AI Agents to understand, query and interact with Perses APIs in a standardized and secure manner. </p> <p>Imagine being able to prompt your favorite AI Agent with questions like: </p> <ul> <li>"How many dashboards are created in the last 5 days in project 'Test Project'?"</li> <li>"What is the default datasource for project 'Test Project'?"<ul> <li>"Is this datasource in proxy mode? and what is the URL?" </li> </ul> </li> <li>"Analyze this dashboard 'Dashboard A' in project 'Test Project'"<ul> <li>Suggest me some improvements to panels and PromQL queries in this dashboard</li> </ul> </li> </ul> <p>As you can see, the possibilities are endless. The Perses MCP Server allows you to interact with Perses in ways that were previously not possible.</p>
