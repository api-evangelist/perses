<h1>Release v0.53.0</h1> <p>Welcome to Perses v0.53.0! In this release, on top of many improvements and bug fixes, we have introduced several changes that break the compatibility with previous versions.</p> <p>These changes have been thought through carefully to improve the overall user experience and maintainability of Perses. We hope even if it will make the upgrade process a bit more complex, you will stay with us and enjoy the benefits of these improvements.</p> <p>While you can read this blog post to have details about the changes and how to upgrade, we are also providing a <a href="https://perses.dev/perses/docs/upgrade-guide/">migration guide</a> that is more condensed and focused on the steps required to upgrade from previous versions to v0.53.0.</p> <p>On a different topic, we are happy to be able to list <a href="https://logz.io/">Logz.io</a> as a new official company using Perses in production. Welcome to the Perses community!</p> <p>If you are a company using Perses or contributing to it and want to be listed as an adopter, please follow the <a href="../../adopters.md">guideline</a>. It is always great to see more and more companies trusting Perses for their monitoring needs. And it will help us to grow the community and make Perses even better.</p> <p>As usual, this blog post does not cover all the changes and improvements included in this release. We are only talking about the changes that should interest you the most. If you want to have a complete list of all the changes, please refer to the <a href="https://github.com/perses/perses/releases/tag/v0.53.0">changelog</a></p>
