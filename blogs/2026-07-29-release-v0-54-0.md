Release v0.54.0 Welcome in the v0.54.0 release ! First of all this release includes several security fixes that patches some breach in the permission system included in Perses, so we strongly recommend to upgrade to this version as soon as possible. Then, you will be happy to know that this release includes new plugins: Jaeger, GreptimeDB, Splunk, LogExplorer, AlertManager and OpenSearch.
